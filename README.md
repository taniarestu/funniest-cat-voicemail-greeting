An entry for the [Funniest Cat Voicemail Greeting](https://make.fun/competitions/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) bounty on make.fun ($2, winner takes all).

## The entry

> You've reached Mochi. I knocked your vase off the shelf, now I'm napping in its box. Leave tuna after the beep.

One line, 111 characters: a voicemail greeting recorded by a cat, in the cat's own voice. The joke is built from two things only cats do, knocking a vase off a shelf and then napping in the box it came in, and it closes on the classic voicemail cue, so the punch lands fast when spoken aloud.

## How it works

`main.py` (Python 3, standard library only, deterministic, no network) writes that single line to `/output/entry.txt`. It asserts the competition gate before writing: 1 to 120 characters, a single line, non-whitespace, valid UTF-8.

Run it:

```sh
python3 main.py
```
